# Fase 18 — Release Candidate

Versão `0.18.0-rc.1`, com schema SQLCipher 14 congelado.

A fase transforma a aplicação validada em uma candidata à versão 1.0. Ela adiciona verificação de fonte reproduzível, hashes das migrations, matriz de upgrades, geração e validação de artefatos, inventário de dependências, documentação de privacidade e segurança, publicação como pré-release e checklist de homologação Windows 10/11.

Nenhuma migration nova é criada.
