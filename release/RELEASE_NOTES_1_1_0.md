# FinnacialUX Desktop 1.1.0

## Manutenção pós-lançamento

- central de manutenção em Configurações;
- janela semanal para atualizações e rotinas técnicas;
- adiamento controlado de verificações automáticas;
- bloqueio opcional de instalação fora da janela;
- exigência de backup íntegro para considerar a operação pronta;
- diário técnico local, sanitizado e opt-in;
- pontuação explicável de saúde operacional;
- schema SQLCipher 14 preservado, sem migration 15;
- nenhuma telemetria externa e nenhum envio automático de logs.

## Segurança

A instalação continua exigindo pacote assinado e pode criar backup criptografado antes de atualizar. O diário técnico fica exclusivamente no dispositivo e nunca contém dados financeiros intencionalmente.
