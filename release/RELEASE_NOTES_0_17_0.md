# FinnacialUX Desktop 0.17.0

## Onboarding e experiência final

Esta versão prepara a experiência de uso para a etapa de Release Candidate.

### Destaques

- primeiros passos persistentes por espaço financeiro;
- conclusão automática baseada em dados reais;
- guia opcional, retomável e reiniciável;
- painel compacto de progresso;
- resumo do próximo passo na visão geral;
- busca global de páginas, ações, configurações e ajuda;
- ordenação por relevância e histórico local;
- ajuda contextual com `F1`;
- central completa de ajuda com `Shift + F1`;
- preferências dedicadas em Configurações;
- proteção integral no modo somente leitura.

### Privacidade

A busca global não indexa dados financeiros e o schema 14 não armazena saldos, descrições ou documentos.

### Banco de dados

- versão do aplicativo: `0.17.0`;
- schema SQLCipher: `14`;
- três novas tabelas técnicas de experiência.

### Dependências

Nenhuma dependência npm ou crate Rust foi adicionada.
