# FinnacialUX Desktop 0.11.0

## Inteligência financeira local

- projeções para 30, 60, 90 e 365 dias;
- cenários explicáveis e simulador sem alteração dos dados reais;
- riscos de saldo, renda comprometida e cobertura de reserva;
- gastos atípicos e comparação previsto versus realizado;
- previsão das metas;
- cenários e leituras persistidos no SQLCipher;
- schema 8 compatível com backups e recuperação;
- nenhuma nova dependência externa.
