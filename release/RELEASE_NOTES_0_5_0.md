# FinnacialUX Desktop 0.5.0

## Novidades

- Atualizações assinadas pelo próprio aplicativo.
- Verificação manual e automática de novas versões.
- Backup criptografado antes da instalação de uma atualização.
- Progresso de download e notas da versão dentro das Configurações.
- Instalador NSIS refinado em português e inglês.
- Variante de instalador offline com WebView2 incorporado.
- Scripts para gerar, validar e publicar releases no GitHub.

## Segurança e dados

- O banco SQLCipher e as chaves do Stronghold permanecem no diretório de dados do usuário.
- A atualização instala a nova versão sobre a existente e não substitui o banco financeiro.
- A assinatura do updater é validada antes da instalação.
