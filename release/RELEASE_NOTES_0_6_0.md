# FinnacialUX Desktop 0.6.0

## Novidades

- Estado da janela restaurado entre execuções.
- Ícone na bandeja do Windows com abrir, bloquear, backup e encerrar.
- Opções para fechar na bandeja, iniciar com o Windows e usar notificações nativas.
- Central de comandos com `Ctrl + K` e novos atalhos de teclado.
- Configurações de acessibilidade para movimento, contraste, foco, densidade e escala do texto.
- Métricas locais de desempenho, banco SQLCipher, backups e armazenamento.
- Nova página de ajuda com pesquisa, atalhos e resumo técnico sanitizado.
- Indicador global de navegação e mensagens recuperáveis.

## Segurança e dados

- Nenhuma migration do banco foi alterada nesta versão.
- SQLCipher, Stronghold, PIN e backups continuam compatíveis com a versão 0.5.0.
- O resumo técnico não inclui valores financeiros, senhas ou lançamentos.
- O fechamento para a bandeja respeita o fluxo de instalação de atualizações assinadas.
